# 踝关节正向运动学求解计算过程

本文说明 `ankle_fk_solver.py` 中 `_solve_pose` 和 `check_singularity` 的计算过程。本文使用普通文本数学表达式，不依赖 LaTeX 渲染器。

## 1. 长度约束

对第 i 根直线模组：

- `aᵢ`：小腿上的固定安装点
- `bᵢ`：脚踝局部坐标系中的安装点
- `R(α, θ)`：由 roll 角 α 和 pitch 角 θ 组成的旋转矩阵

旋转后的脚踝安装点：

> Rbᵢ = R · bᵢ

推杆向量：

> eᵢ = aᵢ − Rbᵢ

推杆长度：

> Lᵢ(α, θ) = |eᵢ| = √(eᵢ · eᵢ)

`_forward_kinematics(alpha, theta)` 返回 `(L₁, L₂)`。

## 2. 雅可比矩阵

雅可比矩阵描述两个关节角的微小变化对两根推杆长度的影响：

> J = ∂(L₁, L₂) / ∂(α, θ)

> J = [ ∂L₁/∂α   ∂L₁/∂θ ]
>     [ ∂L₂/∂α   ∂L₂/∂θ ]

对任意关节变量 q（q 可以是 α 或 θ）：

> Lᵢ = √(eᵢ · eᵢ)

> ∂Lᵢ/∂q = (eᵢ · ∂eᵢ/∂q) / Lᵢ

因为 `eᵢ = aᵢ − R · bᵢ`，所以：

> ∂eᵢ/∂q = −(∂R/∂q) · bᵢ

最终得到：

> ∂Lᵢ/∂q = −[eᵢ · ((∂R/∂q) · bᵢ)] / Lᵢ

因此第 i 行雅可比为：

> [ −eᵢ · (Rα · bᵢ) / Lᵢ,  −eᵢ · (Rθ · bᵢ) / Lᵢ ]

其中：

> Rα = ∂R/∂α
> Rθ = ∂R/∂θ

代码对应关系：

```python
length = math.sqrt(_dot(e, e))
-_dot(e, _matvec(dR_da, b)) / length  # dL/dalpha
-_dot(e, _matvec(dR_dt, b)) / length  # dL/dtheta
```

## 3. `_solve_pose` 的 Newton 迭代

目标是根据目标长度 `l1`、`l2` 求解角度 α、θ：

> f(α, θ) = [ L₁(α, θ) − l₁ ] = [ 0 ]
>            [ L₂(α, θ) − l₂ ]   [ 0 ]

### 3.1 计算残差

代码：

```python
current = self._forward_kinematics(alpha, theta)
residual = (current[0] - l1, current[1] - l2)
```

数学形式：

> r = [ L₁ − l₁ ]
>     [ L₂ − l₂ ]

当 `max(abs(r)) < tolerance` 时，认为求解收敛。

### 3.2 求 Newton 修正量

#### 3.2.1 先理解一元 Newton 法

一元 Newton 法用于求解 `f(x) = 0`。如果当前猜测值是 `x`，函数值为 `f(x)`，斜率为 `f'(x)`，在当前点附近可以用直线近似函数：

> f(x + Δx) ≈ f(x) + f'(x)·Δx

希望下一点正好落在零点上，就令左边等于 0：

> 0 ≈ f(x) + f'(x)·Δx

解出修正量：

> Δx = −f(x) / f'(x)

然后更新猜测值：

> x_new = x + Δx

因此 Newton 法每次都用当前点的斜率估计零点位置，再把当前猜测移动到估计的位置。由于直线只是局部近似，所以通常需要重复多次。

#### 3.2.2 本项目是二维 Newton 法

本项目有两个未知量：

> q = [ α ]
>     [ θ ]

同时有两个长度误差：

> r = [ L₁(α, θ) − l₁ ]
>     [ L₂(α, θ) − l₂ ]

一元 Newton 法中的斜率 `f'(x)`，在二维问题中变成雅可比矩阵 `J`：

> J = [ ∂L₁/∂α   ∂L₁/∂θ ]
>     [ ∂L₂/∂α   ∂L₂/∂θ ]

例如，第一行表示 α、θ 改变时 `L₁` 如何改变；第二行表示它们对 `L₂` 的影响。

在当前角度附近，用二维的一阶近似代替一元的切线近似：

> f(q + δq) ≈ f(q) + J·δq

这里 `δq` 是真正要施加到角度上的变化量。希望下一点的长度误差为零，因此令：

> 0 ≈ r + J·δq

得到线性方程组：

> J·δq = −r

这一步就是 Newton 法的核心：把非线性的长度方程，在当前姿态附近暂时近似成一个二维线性方程组。

#### 3.2.3 代码中的 `da` 和 `dt`

代码先计算正号修正量 `Δq = J⁻¹·r`，而不是直接计算 `δq = −J⁻¹·r`：

> Δq = [ Δα ] = J⁻¹·r
>      [ Δθ ]

对于二维矩阵：

> J⁻¹ = 1/det(J) · [  J₂₂  −J₁₂ ]
>                   [ −J₂₁   J₁₁ ]

因此：

> Δα = (J₂₂·r₁ − J₁₂·r₂) / det(J)

> Δθ = (−J₂₁·r₁ + J₁₁·r₂) / det(J)

这对应代码中的：

```python
da = (j22 * residual[0] - j12 * residual[1]) / det
dt = (-j21 * residual[0] + j11 * residual[1]) / det
```

真正应该采用的 Newton 变化量是 `−Δq`，所以角度更新为：

> α_new = α − step·Δα
> θ_new = θ − step·Δθ

当 `step = 1` 时，这是标准 Newton 更新；当 `step < 1` 时，只执行一部分修正，用于防止一步走得过大。

直观地说：如果当前计算出来的某根推杆比目标长度长，残差对应分量为正，Newton 法会根据雅可比判断两个角度应该向哪个方向变化，以及需要变化多少，最终让两根推杆的残差同时减小。

### 3.3 奇异判断

二维雅可比的行列式为：

> det(J) = J₁₁·J₂₂ − J₁₂·J₂₁

当 `abs(det(J))` 很小时，J 接近不可逆，角度修正量可能非常大且不稳定，因此 `_solve_pose` 会报告接近奇异位形。

### 3.4 阻尼线搜索

标准 Newton 步的 `step` 为 1.0。代码只有在候选姿态使残差下降时才接受更新：

> ||r_new||∞ < ||r||∞

如果残差没有下降，就将步长依次减半：

> 1、1/2、1/4、...、1/128

这可以减少 Newton 步跨过有效解分支或进入不稳定区域的可能性。如果最小步长仍不能降低残差，本次求解失败。

### 3.5 迭代结束

达到 `max_iter` 后，代码允许最终残差放宽到 `tolerance × 10`。若仍未达到要求，则抛出 Newton 迭代未收敛异常。

## 4. `check_singularity` 的目的

`check_singularity(alpha, theta)` 用于评估某个姿态是否接近运动学奇异位形。返回值为：

> (is_singular, min_singular_value)

雅可比的局部关系为：

> [ ΔL₁ ]       [ Δα ]
> [ ΔL₂ ]  ≈ J · [ Δθ ]

如果最小奇异值接近零，说明存在某个角度变化方向，使长度变化非常小。此时通过长度反推角度会变得敏感，Newton 求解也更容易不稳定。

## 5. 最小奇异值的计算

奇异值是 `Jᵀ · J` 的特征值平方根。令：

> G = Jᵀ · J = [ g₁₁  g₁₂ ]
>                 [ g₁₂  g₂₂ ]

其中：

> g₁₁ = J₁₁² + J₂₁²
> g₂₂ = J₁₂² + J₂₂²
> g₁₂ = J₁₁·J₁₂ + J₂₁·J₂₂

G 的较小特征值为：

> λₘᵢₙ = (g₁₁ + g₂₂ − √((g₁₁ − g₂₂)² + 4·g₁₂²)) / 2

因此最小奇异值为：

> σₘᵢₙ = √λₘᵢₙ

代码最后判断：

```python
return min_singular_value < threshold, min_singular_value
```

`_solve_pose` 中的行列式判断用于保护当前 Newton 迭代；`check_singularity` 则提供独立的姿态诊断指标，可以在求解前或运行过程中监测姿态是否接近奇异区域。
